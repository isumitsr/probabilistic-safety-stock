# Analysis notebooks

The project analysis is organized into the following notebooks:

1. `01_data_audit_and_eda.ipynb`
2. `02_data_preparation_and_series_selection.ipynb`
3. `03_time_series_eda.ipynb`
4. `04_forecasting.ipynb`
5. `05_uncertainty_and_safety_stock.ipynb`
6. `06_statistical_inference_and_distribution_analysis.ipynb`
7. `07_inventory_policy_simulation_and_final_evaluation.ipynb`

The numeric prefixes define the execution order. Notebooks 01 through 06 keep the final outcomes outside their statistical calculations. Notebook 07 fixes the policy rules first and then opens `d_1914` through `d_1941` once for final evaluation.

`AAI_USD_Project_1.ipynb` is a collaborator's exploratory notebook. It is retained for reference but is not part of the numbered project workflow.
