# Reports

This directory contains short reports and the final written project outputs.

## Current reports

- [`initial_data_audit_summary.md`](initial_data_audit_summary.md): summarizes the first data checks and the initial EDA results.
- [`data_preparation_and_selection_summary.md`](data_preparation_and_selection_summary.md): records the chronological split, selected series, and join checks.
- [`time_series_eda_summary.md`](time_series_eda_summary.md): summarizes demand profiles, weekly patterns, autocorrelation, and seven-day demand.
- [`forecasting_summary.md`](forecasting_summary.md): compares the validation performance of the three point-forecast baselines.
- [`uncertainty_and_safety_stock_summary.md`](uncertainty_and_safety_stock_summary.md): reports interval calibration and the resulting planning buffers.

Charts used in a report belong in `figures/`. We commit only clear charts that are referenced by a report. Extra working charts stay in the notebooks.
